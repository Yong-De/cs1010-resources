# Practical Exam PE-3

## Overview
- This repository contains the exercises that comprise Practical Exam **PE-3**.  
- Please complete each exercise. You don't have to do them in order.
- The instructions for the exercises can be found in Canvas (if it's a practice exercise) or in a physical document handed to you (if it's a Practical Exam).

## List of exercises in this Volume


1. `prac-changedir`
2. `prac-linux-tree`
3. `prac-parse`
4. `prac-sootopolis`

## Instructions

1. **Compiling**: Use `make` (no other arguments, don't do `make student` etc) to compile any exercise unless the instructions say otherwise. 
2. **Running**: The name of the executable should be specified in the instructions, or the Makefile in the TARGET line. 
3. **Testing**: You can run `make test` to run a limited set of test cases (we will test with more private test cases). You can typically add more test cases via adding a pair of .in and .out files to the `test/test_cases` folder. Alternatively, you can do further testing via running your executable directly and type the input via your terminal. 
4. **Submitting**: You don't have to do anything to submit. We will automatically copy whatever your code is from your pelogin home directory once the PE is over. 

Good luck!
